This does not follow the Yocto Project concept of a layer, but you can look at it as such.
It is used to set together several recipes, and do very well defined tasks, in a way far more simpler to follow
than the Yocto Project or other build sytems.

At the moment, it only supports the pscgdebos variants, and since this moment is already lasting a couple of years, this might as well be the case more years from now.
